# Synthetic creek

Every module in this folder generates data, and none of them asserts anything. The tests that use it live one level up in `tests/`. Reading `tests/` shows what the project claims, and reading `tests/synthetic/` shows what those claims were measured on.

`creek_synthetic.py` builds a fault-free creek with known ground truth: 5 sites on the real flow graph, per-site baselines near the levels the network sits at, a diurnal cycle, noise, and optional spills that attenuate and lag downstream along the edges. It then injects one of 7 fault shapes into a chosen node over a fixed window: (1) `stuck`, frozen with the prediction target frozen too, (2) `stale`, frozen history with a live target, (3) `partial`, frozen plus a fraction of the node's own normal variance, (4) `drift`, a ramp, (5) `spike`, a step change landing on the scored observation, (6) `decouple`, a reflection about the window mean that keeps mean and variance exactly and inverts only the correlation with the node's siblings, and (7) `slow_all`, every node ramping together. Scoring may compare only against the returned `truth` dict. `nested_batch.py` turns one generated window into the batch dict the per-node encoder reads. `baseline_sweep.py` runs the full shape × node × magnitude grid through any detector with `score(batch, nulls)`, which puts a model and a control chart through one code path.

We treat what comes out of here as secondary evidence. A synthetic fault is controlled, since we know which node broke, when, and by how much, and that makes ranking and false alarm rates measurable at all. However, the fault shapes are ones somebody chose, and a detector can only be measured against faults that were thought of. The primary evidence is `tests/events.yaml`, the real labelled events from the creek, scored in `tests/test_anomaly_detection.py`. Where the two disagree, the real events win.

The folder is still load-bearing and should stay. `tests/test_node_adapter.py` asserts that a synthetic window and a real one produce identical node tensors, and the generator thus pins the real ingestion path to a known-correct shape.
